# CriSpy — Minecraft / Blender portfolio

Статическое портфолио на HTML, CSS и JavaScript. Сборка, npm-пакеты, API-ключи и серверная часть для сайта не нужны. Все изображения, шрифты и иконки загружаются локально.

[Десктопный дизайн](docs/preview-desktop.webp) · [Мобильный дизайн](docs/preview-mobile.webp)

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Для размещения на статическом хостинге нужны `index.html`, `styles.css`, `app.js`, каталог `assets` и исходные `render*.png` / `render*.jpg`: ссылки «Оригинал» ведут к исходным изображениям. Публикация из корня подходит для GitHub Pages; все пути относительные, поэтому сайт работает и в подкаталоге.

## Что умеет сайт

- Подборка из пяти работ с раскрытием всех 15; поиск по названию, фильтры сцен, аватаров и экспериментов.
- Избранное в `localStorage`, синхронизация между вкладками, корректная работа при запрете хранилища.
- Просмотр в нативном `dialog`: стрелки, Escape, свайп, увеличение, возврат фокуса, оригинал и копирование прямой ссылки.
- Ссылки на состояние галереи: `?filter=avatars`, `?q=костра`, `?work=render12`. Их можно сочетать.
- Калькулятор минимальной стоимости по исходному прайсу: 30 / 50 / 80 / 120 ₽; дополнительный персонаж в сцене +10 ₽. Точная стоимость согласовывается с автором.
- Кнопка заказа формирует личное сообщение в Telegram с типом рендера, количеством персонажей и вашей идеей. Данные формы никуда не отправляются до перехода в Telegram и не сохраняются в браузере.
- Копирование контакта, мобильная навигация, индикатор чтения, активный раздел меню.
- Без JavaScript остаются все работы, оригиналы, цены, контакты и навигация. Для пользователей с `prefers-reduced-motion` отключаются анимации и плавная прокрутка.

## Структура

- `index.html` — контент, 15 работ и SVG-иконки; доступен без JavaScript.
- `styles.css` — адаптивная композиция, локальные шрифты, состояния интерфейса.
- `app.js` — интерактивность без сторонних библиотек.
- `assets/images` — адаптивные WebP-превью шириной до 480, 960 и 1600 px. Оригиналы не изменены.
- `assets/fonts` — Manrope и Unbounded с кириллицей, лицензии SIL OFL рядом с файлами.
- `tests/test_portfolio.py` — браузерные регрессионные проверки; поднимают свой временный HTTP-сервер.

## Обновление работ

Карточки находятся в `#gallery`. Для новой работы нужны уникальный `data-id`, `data-title`, `data-original`, группа `data-group` (`scenes`, `avatars` или `experiments`) и соответствующие ссылки `data-open` / кнопка `data-favorite`. Категория и название написаны в HTML и используются в просмотрщике.

После добавления работ обновите число работ в текстах страницы и правила генерации изображений. Не заменяйте авторские оригиналы сжатыми превью.

Для повторной генерации существующих WebP нужен Pillow:

```sh
python3 -m pip install -r requirements-dev.txt
python3 scripts/optimize_images.py
```

Генератор запускается из любой директории и воспроизводимо перезаписывает только `assets/images`. Шрифты уже включены в репозиторий, скачивать их при запуске сайта не нужно.

## Проверки

```sh
python3 -m pip install -r requirements-dev.txt
python3 -m playwright install chromium
python3 -m unittest discover -s tests -v
node --check app.js
```

Если системный Chromium уже установлен, скачивать браузер не нужно. Тесты используют `chromium` из PATH либо путь из `CHROMIUM_PATH`, затем установленный браузер Playwright. Python, Pillow и Playwright относятся только к разработке: посетителю и статическому хостингу они не нужны.

Обоснование визуальных решений и источники вдохновения — в [DESIGN.md](DESIGN.md).
